
## Семинар №4. Файлы, исключения и стандартная библиотека Python

### 1. Анализ текстового файла

Напишите программу, которая читает текстовый файл и выводит:

* количество строк;
* количество слов;
* количество символов;
* длину самой длинной строки.

При обработке файла не загружайте всё содержимое целиком в память.

---

### 2. Статистика числового файла

В файле `numbers.txt` записаны целые числа, по одному в строке.

Напишите программу, которая:

* считывает числа;
* вычисляет минимальное и максимальное значение;
* вычисляет среднее арифметическое;
* записывает результаты в `result.txt`.

Предусмотрите ситуацию, когда файл содержит строки, которые нельзя преобразовать в число.

```json
    {"name": "Bob", "age": 21, "score": 76},
```

### 8. Безопасное чтение файла

Напишите функцию:


которая возвращает содержимое файла.

Функция должна корректно обрабатывать:

* другие ошибки операционной системы.

Для разных ситуаций необходимо выводить разные сообщения.

Не допускается использовать конструкцию:

```python

```

### 10. Собственная иерархия исключений

```text

├── InvalidAmountError
├── InsufficientFundsError
└── AccountBlockedError
```

### 13. Контекстный менеджер для измерения времени

Создайте контекстный менеджер:

```python
with Timer():
    some_function()
```

После выхода из блока он должен вывести время выполнения блока.

Используйте:

```python
time.perf_counter()
```

Реализуйте сначала через класс с `__enter__` / `__exit__`, а затем через `contextlib.contextmanager`.

### 14. Контекстный менеджер для файла журнала

Создайте контекстный менеджер:

```python
with log_operation("operation.log", "Data processing"):
    ...
```

При входе в контекст записывается:

```text
START: Data processing
```

При выходе:

```text
END: Data processing
```

Если внутри блока возникло исключение, вместо `END` должно записываться:

```text
ERROR: Data processing
```

Само исключение при этом должно продолжить распространяться.

### 15. File-like object


которая получает **файлоподобный объект** и возвращает количество строк.

Функция должна работать как минимум с:


**21. Проверка логина**

Напишите функцию:

```python
def is_valid_login(login):
    ...
```

Логин считается корректным, если:

* содержит от 4 до 16 символов;
* начинается с латинской буквы;
* содержит только латинские буквы, цифры и символ `_`.

Примеры:

```text
user_123    → True
admin       → True
123user     → False
ab          → False
user-name   → False
very_long_username → False
```

Функция должна возвращать `True` или `False`.

**25. Извлечение данных из строк лога**

Дан набор строк:

```text
logs = [
    "2026-09-24 10:15:32 INFO User 123 logged in",
    "2026-09-24 10:16:04 ERROR User 456 authentication failed",
    "2026-09-24 10:17:21 INFO User 123 opened page",
    "2026-09-24 10:18:45 WARNING User 789 too many requests",
    "2026-09-24 10:19:02 ERROR User 123 database connection failed",
]
```

С помощью регулярного выражения обработайте каждую строку и получите:

1. дату и время;
2. уровень сообщения (`INFO`, `WARNING`, `ERROR`);
3. идентификатор пользователя;
4. текст сообщения.

Например, для строки:

```text
2026-09-24 10:16:04 ERROR User 456 authentication failed
```

должен получиться набор данных:

```python
{
    "datetime": "2026-09-24 10:16:04",
    "level": "ERROR",
    "user_id": "456",
    "message": "authentication failed"
}
```

Для решения рекомендуется использовать **именованные группы** регулярного выражения: `(?P<name>...)`.
